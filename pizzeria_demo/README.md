# Pizzeria Turku Static Website

An artisan-quality, fully responsive static website designed for **Pizzeria Turku**, an authentic Neapolitan wood-fired pizza restaurant based in Southwest Finland. Crafted with pure semantic HTML5, clean reusable CSS, and fast-loading modular architecture.

## Features

- **Cozy & Traditional Polish Design:** Elegant cream background, warm dark brown text contrast, and rich tomato-red highlights with serif headings.
- **Responsive Architecture:** Pixel-perfect layout tailored across mobile displays up to ultra-wide desktop monitors.
- **Accessible (A11y):** Incorporates semantic structuring, descriptive ARIA indicators, clear focus visual highlights, and keyboard navigability.
- **Fast Core Performance:** Low network footprint, zero framework overhead, and standard lazy-loading image configurations.
- **Interactive Component Controls:** Integrated mobile menu drawer, slick category tab switching for the menu, responsive sticky bottom CTA widget, and a client-validated booking form.
