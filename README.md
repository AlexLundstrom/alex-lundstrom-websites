# Alex Lundström — Static Custom Portfolio

This is a modern, blazing-fast, static export website designed for **Alex Lundström**, a professional website building service located in Turku, Finland.

## Color Scheme & Identity
- **Cream Background**: `#FCFAF5`
- **Warm Forest Green**: `#1F3F2E`
- **Refined Gold Accent**: `#C5A059`

## Key Features
- **Dual Language Integration**: Full English and Finnish support with state management without complex routing.
- **Linear Book Progression**: Designed to guide the reader page by page (Home -> Services -> About -> Demos -> Contact) using simple sequential action footers.
- **Dynamic Service Cards**: Built on top of strict JSON menu schemas, rendered on page load.
- **Static Demo Viewports**: Live code sandbox previews (`example1.html`, `example2.html`) wrapped inside custom browser frame frames.

## Technical Details
- Complete Vanilla Stack: Built with HTML5, semantic CSS3 grid systems, and fast Vanilla JavaScript.
- Lightweight: Free of large framework dependencies, making the site optimal for hosting solutions like GitHub Pages, Vercel, or Netlify.
